# Changelog

All notable changes to SessionBridge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Local-first Rust CLI and Tauri operator console.
- Autonomous Task planning, Claims, WorkAttempts, Evidence, review, integration,
  durable waits, completion conclusions, and Task workgroup chat.
- Recoverable Task launch and invitation workflows.
- Shared runtime reconciliation for Git integration integrity, Requirement
  coverage, Deliverable verification, and completion state.
- Agent-selected join nicknames displayed across chat and diagnostics.

### Security

- Private invitation and context artifacts, hashed tokens, parameterized SQL,
  fixed Git argv, structured redacted logs, and repository binding checks.
