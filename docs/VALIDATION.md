# 工作群重构验证记录

## 已通过

- Rust：3 项复用 Git 检查、4 项新版协议/整合测试，共 7 项；测试预编译后使用 60 秒超时。
- 前端：2 项传输与错误传播测试，TypeScript 检查和 Vite 生产构建。
- Clippy 严格检查、rustfmt、cargo-machete、diff 空白检查。
- 真实本地服务与 SQLite，搭配 Claude/Codex 原生帧协议测试进程：MCP 握手、单播、ACK、停止、恢复和后台退出。
- 原生夹具还验证了重复初始化请求的幂等返回、失效 Codex thread 的一次性新建回退，以及暂停与初始化竞争后的最终离线状态。
- 真实 Claude CLI，搭配本地确定性 Messages API：4 次 API 请求完成 Skill 读取、inspect 和 READY。此项不调用收费模型。
- 浏览器连接真实 Rust 后端：创建群、添加成员、单播、广播、草稿恢复；390、1024、1380px 页面横向溢出均为 0。
- 独立截图复核；系统消息长 ID、模型必填提示已修正。图标具备可访问名称与悬停提示。
- CLI release 和 Tauri 无安装包 release 构建。
- 协作 Skill 结构验证。

## 关键行为

协议测试验证了跨群访问拒绝、重复请求幂等、同 ID 异内容冲突、伪造或过期 READY 拒绝、未交付消息不能 ACK、移除后凭证失效、数据恢复。

整合测试使用真实 Git 仓库验证 worktree 隔离、真实提交要求、执行者不能自验收、脏工作区保护、目标推进后的重新验证、自动合入与重复完成恢复。

补充检查覆盖流式消息的变更游标、上游重开导致下游失效，以及宿主验证命令不能写出整合 worktree。
