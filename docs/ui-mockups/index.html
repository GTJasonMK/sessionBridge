SessionBridge · Operator Console

UI 重设计 Mockups

参照 A4N 的 iOS / 简约 / 朴素 / 丝滑风格，将主色微调为静谧靛蓝。 本目录产出真实可打开的前端预览，按页面与组件职责拆分，字段对齐现有 Tauri GUI 与 Rust 后端能力 （Workspace、Task、Dashboard、Chat、Launch、Prompt、Doctor）。

风格 iOS · Glass · 微动效 范围 仅布局与样式 · 不改业务契约 数据 模拟 task_snapshot 主题 浅色 / 深色
组件库 Workspace 门禁 概览 工作项 Agent 群聊 活动 诊断 发布任务 Agent 提示词
设计原则
  • 操作者路径：发布任务 → 接入 Agent → 观察结果；不替 Agent 做决策。
  • 信息架构对齐现有 GUI 六页：概览 / 工作项 / Agent / 群聊 / 活动 / 诊断 + 门禁与两个对话框。
  • 视觉：暖灰背景、纸面卡片、半透明顶栏、左侧选中条、柔和阴影与 160–320ms 缓动。
  • 文件职责：css/ 令牌与样式 · js/ 模拟数据与壳层 · pages/ 页面 · components/ 组件展柜。

信息架构

IA

三栏 Operator Console：侧栏（Workspace + 任务列表 + 页面导航）· 主区（页面内容）· Inspector（任务元数据 / 完成条件 / 相位操作）。

侧栏
Workspace 切换 · 任务列表（phase 点）· 六页导航 · 主题 · 实时同步状态
主区
玻璃顶栏（标题 + phase + 刷新 / 提示词 / 发布）· 可滚动内容区
Inspector
Task ID / 分支 / 自治策略 / Epoch / Plan · 完成条件 · 暂停/恢复

落地到 gui/ 的建议

Next
不在本轮改 React 代码，仅交付可预览 mockup。后续实现时可：
  • 将 tokens.css 变量迁移到 gui/src/styles.css 的 :root。
  • 按页面拆分 App.tsx 为 pages/* + components/*，壳层复用本目录 IA。
  • 保留现有 Query 刷新间隔与 API 契约；只换 class 与布局。
  • 动效尊重 prefers-reduced-motion，与 polish 层一致。
